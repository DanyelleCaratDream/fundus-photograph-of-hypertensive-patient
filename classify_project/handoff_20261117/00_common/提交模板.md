# 提交模板（每位组员每份交付照此写首页）

```markdown
# 交付：<任务编号> <标题>

- 负责人：
- 提交日期：
- 输入文件与 sha256：
  - <文件>  <sha256>
- 运行环境：
  - Python / numpy / sklearn / 其他
- 运行命令：
  - `<命令>`
- 运行耗时：

## 1. 方法（3–6 行）
<用什么数据、什么统计量、bootstrap 设置、代码入口>

## 2. 结果
<表：逐 arm / 逐 seed；数量与比例；CI 与 B、seed>

## 2.5 结论卡（强制，导师 2026-11-17 定）

每条结论必须按 `结论卡模板.md` 给出五要素：
**结论 / 证据文件 / 计算方法 / 可复现脚本 / 局限性**。
另交 `结论卡.csv`；报告与结论卡一一对应，缺卡结论视为未提交。

## 3. 与现有数字的差异
<逐项：原数字 / 复算 / 差值 / 原因；没有差异也要写"一致">

## 4. 限制与禁止事项确认
- [ ] 未改输入、未重选 checkpoint、未按 test 调参
- [ ] CI 未解释为患者级/显著性
- [ ] 所有结论可追溯到文件与代码位置

## 5. 交付文件清单
| 文件 | 说明 |
```

## 命名

- 报告：`A1_统计复核报告.md`、`A2_T3复算报告.md`、`B1_错误分析与校准报告.md`、`B2_实现审计报告.md`
- 数据：`*.csv`；图：`figs/*.png|pdf`
- 脚本：`recompute.py` / `analyze.py`（必须能从包根目录直接跑）
