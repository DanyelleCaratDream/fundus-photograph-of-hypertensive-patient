# DL-EX-032（T3）复算输入说明

> 实验问题：**固定训练预算下，用合成图替代约 30 个/轮的真实图抽样机会，效果如何？**
> 不得写成"额外增加合成数据改善分类器"。

## 1. 设计（预注册，不得更改）

| 项 | 内容 |
|---|---|
| A0 | 真实训练集 552 张（官方 split） |
| A1 | 真实 552 + 32 张 **128px** 合成 severe（池 584），每轮无放回抽 552 |
| A2 | 真实 552 + 32 张 **256px** 合成 severe（池 584），每轮无放回抽 552 |
| seed | 42 / 52 / 62（三组同 seed） |
| 轮数 | 30；固定 1050 optimizer steps（每轮 35 步，末批 8 张） |
| 类别权重 | 冻结：1.15 / 0.985714 / 0.985714 / 0.907895（三组同用） |
| 抽样 | 只由 `(seed, epoch)` 决定；A1/A2 两池文件名顺序相同 → 同 seed 抽到同一批合成图 |
| 模型选择 | 每 5 epoch 按 **val** QWK；test 只在冻结后评一次 |
| 确定性 | `use_deterministic_algorithms(True)`（warn_only=False）+ cudnn.deterministic + 关 benchmark；CUBLAS_WORKSPACE_CONFIG=:4096:8 |

## 2. 输入文件

- `t3_runs/{A0,A1,A2}_20261117.json`：每组 3 个 run 的指标 + 训练记录 + 曝光明细。
- `predictions/{arm}_seed*.json`：逐图预测，格式同 `00_common/数据与产物说明.md`。
- `run1_no_dump/`：补跑前首轮（无逐图落盘）的汇总 JSON。
  **已核对**：两轮 9 个 run 的指标、`epoch_stats`、`exposure.summary` 逐位一致；
  可自行复核，用来确认补跑没有改变实验。
- `T3_合成池清单_20261117.csv`：两个合成池各 32 张的文件名、生成 seed、样本序号与 sha256；
  两个池同名文件对应同一条件样本（128/256 配对）。

## 3. 训练记录字段（复算时要核对的）

| 字段 | 期望 |
|---|---|
| `optimizer_steps` | 每次 run 均 **1050** |
| `class_weights_used` | 每次 run 均 **1.15 / 0.985714 / 0.985714 / 0.907895** |
| `fixed_draws` | A0 = null；A1/A2 = 552 |
| `epoch_stats` | A1/A2：30 条，每条 `drawn=552`、`real+synth=552`、`batches=35`、`last_batch=8` |
| `exposure.summary.real.mean` | A0 = 30.0；A1/A2 ≈ 28.35–28.36 |
| `exposure.summary.synth.mean` | A0 = null；A1/A2 ≈ 28.2–28.5 |
| `best_epoch` | 每 5 的倍数（或末轮） |
| `deterministic_flag` | true |
| `determinism.*` | 三开关为 true/true/false；环境变量 `:4096:8` |

## 4. 需要你独立完成

1. 从 `predictions/` 重算每个 seed 的 QWK、bAcc、macro-F1、severe recall、逐类 recall。
2. 计算 **同 seed** 的 ΔA1−A0、ΔA2−A0；再做配对分层 bootstrap CI（见 `00_common/指标与CI规范.md`）。
3. 核对上表所有训练记录字段；核对 A1/A2 同 seed 的 `epoch_stats` 是否完全一致。
4. 输出"原汇总 vs 独立复算"逐项差异表。

## 5. 判定边界（写报告时必须遵守）

- `0.02` 是**实际意义参考幅度**，不是显著性门槛；"超过 0.02 且三 seed 同向"也不等于统计显著。
- 三组同 seed 是**种子层面的配对设计**：A0 每轮遍历 552 张，A1/A2 每轮抽 552 张（池 584），
  不是逐 batch 一一配对。
- 128 与 256 组使用相同 seed、相同抽样索引、对应条件图配对；不要把两组当成独立重复样本合并。
- 确定性只减少"同环境、同 seed、同配置"的重复运行差异，不消除数据组成与 seed 间差异。
- 不得外推到患者级独立或临床泛化。
