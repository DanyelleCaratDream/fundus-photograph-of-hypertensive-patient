## B1. 错误分析与校准（现在即可开始）

**输入**

- `00_common/predictions/A{0,1,2}_seed{42,52,62}.json`
- `00_common/指标与CI规范.md`（类别顺序与概率定义）
- `03_B_errors/ECE规范.md`

**要做**

1. 每个 arm × 每个 seed：混淆矩阵（**数量 + 行归一化比例**）。
2. severe 被误判为 normal / mild / moderate 的数量和比例。
3. moderate 的表现（召回、主要误判方向）。
4. ECE 与 reliability diagram（分箱规则、每箱样本数必须写）。
5. 跨 seed 是否存在一致的错误模式（哪些图稳定被错分）。
6. 明确指出：11-12 主结果无逐图预测，本分析只覆盖 11-15 重跑。

**禁止**

- 只展示最有利的 seed；只报比例不报数量。
- 把小样本 ECE 的细微差异写成"校准改善"。
- 把探索性观察写成确定结论。

## B2. 实现与文献一致性审计

**输入**

- `04_B_audit/code_snapshot/train_classifier_current.py`（当前工作区）
- `04_B_audit/code_snapshot/train_classifier_HEAD_c663fb3.py`（HEAD）
- `04_B_audit/代码快照说明.md`
- `04_B_audit/论文与方法依据.md`
- `04_B_audit/审计对照表模板.csv`

**要核查**

1. Logit adjustment 公式是否与原文一致；τ 是否**只在 val** 上选。
2. DRC 两阶段：阶段 1 学表示、阶段 2 冻结骨干 + 重初始化 + 类平衡重训分类头，是否与原文一致。
3. Weighted CE 是否按逆频率、权重公式与报告一致。
4. seed / 初始化 / 轮数 / checkpoint 选择（每 5 epoch 按 val QWK）是否与报告一致。
5. 所有与原论文不同或**无法确认**的地方。

**每条必须写**

| 字段 | 说明 |
|---|---|
| 论文依据 | 公式/小节/页码 |
| 代码位置 | 文件:行号 |
| 实际行为 | 一句话 |
| 判断 | 一致 / 有偏差 / 无法确认 |
| 可能影响 | 对结论的影响；无法确认时写"无法判断" |

**禁止**

- 修改训练代码；重新训练或重选模型；只报有利结果；把偏差藏在结论里。
