# 验收清单：组员 B

## B1 错误分析

- [ ] 每个 arm × 每个 seed 的混淆矩阵齐全（3×3=9 个）
- [ ] 每个矩阵同时给数量与行归一化比例
- [ ] severe 被误判为 normal / mild / moderate 的数量与比例
- [ ] moderate 的召回与主要误判方向
- [ ] ECE：M=10、箱边界、逐箱 `n_b/conf_b/acc_b`、空箱注明
- [ ] reliability diagram 数据可复现，图注含输入文件
- [ ] 跨 seed 一致错误模式有明确判据（如 ≥2/3 seed）
- [ ] 全程标注"探索性"，未把 ECE 差异写成校准改善
- [ ] 未只报最有利 seed；未只报比例不报数量
- [ ] 明确写出只覆盖 11-15 重跑（11-12 无逐图预测）

## B2 实现审计

- [ ] 12 项核查全部有结论（一致/有偏差/无法确认）
- [ ] 每项含：论文依据、代码位置（文件:行号）、实际行为、判断、可能影响
- [ ] τ 只在 val 选择——给出代码位置
- [ ] DRC 两阶段的三点（冻结/重初始化/类平衡）分别核对
- [ ] 加权 CE 公式与报告描述一致
- [ ] checkpoint 选择（每 5 epoch val QWK）与 test 只评一次核对
- [ ] 明确写出"无法确认历史运行使用哪份代码"
- [ ] 未修改代码、未重训、未重选模型
- [ ] 文献缺失的条目判"无法确认"，没有凭印象下结论
