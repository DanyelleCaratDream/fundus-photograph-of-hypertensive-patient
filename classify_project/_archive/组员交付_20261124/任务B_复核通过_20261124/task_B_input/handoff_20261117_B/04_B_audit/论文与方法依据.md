## 1. Post-hoc logit adjustment（A1）

- 文献：Menon, Jayasumana, Rawat, Jain, Veit, Kumar.
  *Long-tail Learning via Logit Adjustment*. **ICLR 2021**. arXiv:2007.07314。
- 本地文件：`papers/Menon2021_LogitAdjustment_arXiv2007.07314.pdf`
- 对应实现：post-hoc 形式，`argmax_y [ f_y(x) − τ·log π_y ]`；τ 只在 val 上选。
- 审计要核对：公式形式、π 的定义（训练集类频率）、τ 的作用位置（post-hoc 而非 loss 内）。
- 注意：论文也给了 τ=1 与调参两种设置；项目用的是在 val 上调 τ，属于论文框架内的变体。

## 2. DRC 两阶段（A2）

- 文献：Kang, Xie, Rohrbach, Yan, Gordo, Feng, Kalantidis.
  *Decoupling Representation and Classifier for Long-Tailed Recognition*. **ICLR 2020**. arXiv:1910.09217。
- 本地文件：`papers/Kang2020_Decoupling_arXiv1910.09217.pdf`
- **对应关系：作者已确认项目参照的是这篇（2026-11-17）。**
- 对应实现：阶段 1 按原始分布训练；阶段 2 **冻结骨干、重初始化分类头、类平衡采样**只训练 fc。
- 审计要核对：阶段 2 是否真的冻结 backbone（含 BN 统计）、是否重初始化 fc、
  采样是否类平衡、训练轮数与学习率是否与项目配置一致。

## 3. 加权交叉熵（A0/A1/A2 共用）

- 公式（代码事实）：`w_c = (N / (n_c + 1e-6)) / 4`，N=训练集总数，n_c=类样本数。
- 无外部论文依赖；审计只核对公式与报告描述是否一致。
