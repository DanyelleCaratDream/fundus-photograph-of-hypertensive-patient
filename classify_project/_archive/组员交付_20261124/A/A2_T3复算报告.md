## 1. 方法

指标、分层和配对方式与 A1 相同，定义见 `A1_统计复核报告.md` 第 1 节。test 仍是 71 张，四类 18、20、20、13。九个预测文件的路径和 `y_true` 顺序一致。

Δ 按同一训练 seed 配对：seed 42 的 A1 对 seed 42 的 A0，A2 同样。合并 Δ 是三个 seed 指标的平均之差。图像索引在三个 arm 和三个 seed 之间共用。B=1000，`Generator` 种子 20261117，线性百分位。seed 不参加重抽样，区间只重抽 test 图像，三个 seed 的预测保持不动。

训练记录只做字段核对。`val_qwk` 没有对应的验证集逐图预测，不能重算。合成池清单里的图像 sha256 也不能重算，因为本包没有这些图像。

0.02 是设计中的幅度参考。三个 seed 同号，或平均差超过 0.02，在这里都不进入假设检验。A1 与 A2 共用抽样索引和条件图配对，不合并成六个独立样本。

### C-09 九次运行的步数、选择轮次和确定性开关与设计一致

九次 run 的 `optimizer_steps` 都是 1050。`best_epoch` 为 A0 的 25、10、10，A1 的 10、15、10，A2 的 15、20、15，都是 5 的倍数。`deterministic_flag` 为 true。三次顶层记录里，`deterministic_algorithms` 与 `cudnn.deterministic` 为 true，`cudnn.benchmark` 为 false。`cublas_workspace_config` 为 `:4096:8`。

这些开关约束的是同一环境、同一 seed、同一配置下的重复运行。它们不消除三个 seed 之间的差别，也不消除 A0 全量真实图与 A1、A2 抽样组成之间的差别。

`val_qwk` 仍是记录值。没有验证集逐图预测，不能核对“每 5 个 epoch 按 val QWK 选择”是否选中了验证集上的最大者，只能核对所选轮次落在允许的轮次上。

### C-10 九次类别权重相同，等于文档六位小数的 float32

九个 run 的 `class_weights_used` 是同一个向量：

`[1.149999976158142, 0.9857140183448792, 0.9857140183448792, 0.907895028591156]`

它等于 `float32(1.15, 0.985714, 0.985714, 0.907895)`，也就是说明中冻结的六位小数。训练集 120、140、140、152 的未舍入权重 `552/(4*n_c)` 再转成 float32 后，与这个向量的最大绝对差是 2.98×10^−7。差别来自先保留六位小数再存成 float32。九次之间没有另外的权重。

### C-11 抽样合计可以对上；A0 没有逐轮记录

A1、A2 的六个 run 都有 30 条 `epoch_stats`。每条 `drawn=552`，`real+synth=552`，`per_class` 之和为 552，`batches=35`，`last_batch=8`。逐图 `count` 的总和、真实图总和、合成图总和，分别等于 30 轮对应字段的总和，也等于 `exposure.summary.total_draws`。`fixed_draws` 为 552，`train_n` 为 584，其中真实 552、合成 32。

三个 seed 的真实图平均曝光是 28.3641、28.346、28.3623，合成图是 28.2188、28.5312、28.25。从 584 张里每轮无放回抽 552 张、共 30 轮，均匀期望是 30×552/584 = 28.3562。seed 52 的真实图均值 28.346 略低于说明里约 28.35～28.36 的范围，合成图均值 28.5312 略高于约 28.2～28.5 的范围。这两项的逐图合计仍与逐轮合计相同，观测范围比说明中的近似区间略宽。

A0 的 `epoch_stats` 为 null，`fixed_draws` 为 null，`train_n` 为 552，合成图张数为 0。因此不能从逐轮记录核对 A0 的 `batches` 和 `last_batch`。A0 的 552 张真实图曝光都是 30，合计 16560，与 `summary.total_draws` 一致，也与 30 轮全覆盖一致。A0 的 `optimizer_steps` 仍是 1050。

`epoch_stats` 只有每轮张数，没有每轮文件名。逐图曝光能与逐轮合计核对，不能还原某一轮抽到了哪一张。

### C-12 同一 seed 的 A1 与 A2 用了同一套抽样计数，合成文件名成对

seed 42、52、62 上，A1 与 A2 的 30 条 `epoch_stats` 完全相同，真实图的逐文件曝光完全相同，合成图按文件名对齐后的曝光也完全相同。每个 seed 有 32 个合成文件名。

`T3_合成池清单_20261117.csv` 中，128 池和 256 池各 32 行。32 个文件名相同，相同文件名的 `gen_seed` 和 `sample_index` 也相同。曝光里的合成文件名与各自池的清单一致。图像字节不在本包内，清单上的 sha256 没有从像素重算。

因此，记录支持“同一 seed、同一抽样索引、同名条件图”这一配对。它不表示每个 batch 的内部顺序也已逐张核对。

### C-13 A1 相对 A0 的三个 QWK 差都为正，图像级区间包含 0

QWK(A1)−QWK(A0) 为 +0.0422、+0.0410、+0.0607，平均 +0.0479，三个差的样本标准差为 0.0110。平均差大于 0.02，三个 seed 同号。

合并后的 balanced accuracy 差是 +0.0147，区间 [−0.0312, +0.0643]。macro-F1 差是 +0.0094，区间 [−0.0424, +0.0613]。severe recall 差是 +0.0256，区间的下端在 1e-15 以内为 0、上端为 0.0769，即 1/13。三个区间都包含 0。

### C-15 两份训练 JSON 的字节相同

`run1_no_dump/{A0,A1,A2}_20261117.json` 与 `t3_runs` 下的同名文件 sha256 相同。两处的指标、`epoch_stats` 和 `exposure.summary` 因此逐字节相同，不只是四舍五入后相同。含逐图预测的这一轮与这些 JSON 中的 test 指标一致，见 C-08。字节相同不能再分离出另一份内容不同的首轮日志。
