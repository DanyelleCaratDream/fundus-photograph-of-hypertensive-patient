## 一、30 秒结论

- **历史上生成得最像真的方案**：CFM@256（作者目检 97/100，FID 121.84 vs D3 222.69）。
- **方法上的最优配方**：FiLM 条件 UNet + L1+LPIPS 损失 + CFM（OT 路径速度预测）+ A 域预训练迁移。
- **一句话**：它好不是因为"新"，而是因为前几代模型各自帮我们排除了一个死因；但**"已确立的最优"还为时过早**——数据不纯、历史权重带缺陷、纯 severe 从零尚未走通。

---

## 二、六环因果链：每一环排除一个死因

| 环节 | 死因 | 关键证据 |
|:--|:--|:--|
| ① VAE | **模糊天花板**：像素级 MSE 的最优解是条件均值，细节被平均掉 | FID 188.4 但 C2ST 0.9992；800→1200 轮肉眼无差 |
| ② GAN | **判别器记忆**：小样本下判别器"背题"远易于生成器"学画" | WGAN-GP 2 epoch 内 Critic 151→−398；削弱版 2770 轮无变化 |
| ③ DDPM / 条件扩散 / Palette | **MSE 病灶溶解**：暗背景占 95%，最优策略是"预测安全暗色"，亮病灶被拉暗 | 溶解跨架构复现；与架构无关 |
| ④ L1+LPIPS | **修复**：L1 对高亮离群不敏感 + LPIPS 感知约束（t<200，权重 0.1） | 出血代理 0.254→1.137（**4.5×**）；FID 200.2→178.8 |
| ⑤ 迁移 | **信息量瓶颈**：61~193 张教不会眼底全貌；A 域预训练 + FiLM 结构先验补足 | D3（迁移）胜 D4（从零），四组裁决两臂一致 |
| ⑥ CFM | **真实感**：VP+ε 路径 → OT 线性路径+速度预测，路径更直、目标更稳、原生 256 | FID 222.69→**121.84（−45%）**；BRISQUE 13.21 逼近真实 11.02 |

**叠加关系**：FiLM 解决"结构先验"，L1+LPIPS 解决"病灶溶解"，迁移解决"信息量"，CFM 解决"真实感"——缺一不可。

## 三、为什么说它比前面的好（答辩口径）

1. **不是参数碰运气，是单变量归因**：MSE vs L1+LPIPS 是同架构、同数据、只换损失的受控消融；D3 vs D4 是同数据、只换初始化的受控对照。
2. **每一代都有明确的失败机理**，不是"效果不好"四个字：模糊、判别器记忆、病灶溶解，各有可复现证据。
3. **最终指标是"取舍后的最优"**：CFM@256 在全部分布/感知指标领先，但病灶代理仍弱于 D3（0.204 vs 0.754）——这是真实性 vs 病理保真的取舍，我们没有掩盖。

## 四、必须交代的边界（答辩不能回避）

| 边界 | 事实 | 影响 |
|:--|:--|:--|
| 数据不纯 | cfm256 用 193 混合池（132 网络图 + 61 老师 severe），**不是纯 HR severe** | 只能主张"混合数据+迁移能生成逼真眼底" |
| 历史权重带缺陷 | 增强错位（图像翻转/旋转时 cond mask 未同步）影响所有条件模型 | 主指标（FID/目检）可参考，条件跟随类结论需降级 |
| 渗出加权作废 | 3× 损失尺度 + 增强错位 | cfm256_lesion 仅探索性，不作方法证据 |
| 纯 severe 从零未走通 | 61 张 128px 试点 9,600 步失败（噪点/结构崩） | 正在分阶段续训验证"没训够 vs 数据不足" |
| 单种子 / 无医生盲评 | 全部训练 seed 42；97/100 是作者自检 | 不声称统计优势或临床可用性 |

## 五、当前正在回答的问题

> 61 张纯 HR severe、从零、修复管线，**额外优化步数能否让结构出现？**

- 已跑：9,600 步（320 轮，batch2，lr 1e-4 固定）→ 失败；
- 进行中：续训到 15,000 步（只改步数，不动 lr/batch/损失/增强）；
- 判断点：15k → 20k → 30k，每处固定 seed 出图看**结构 / 噪点 / 多样性 / 记忆**，不看 loss 单一指标；
- 若 20k 仍无结构 → 转路线 B（A 域预训练 + 61 微调，需导师批准口径）。

## 六、一句话收尾

> 本项目的方法贡献不是"提出了一个新模型"，而是**用一条可复现的失效链，把"小样本医学图像生成为什么难"拆成了可验证的六个环节，并在每一环给出证据与修复**；CFM@256 是这条链目前的终点，而不是起点。
