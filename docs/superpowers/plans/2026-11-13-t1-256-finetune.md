# T1-256 微调实验 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从 T1@128 的 raw 权重出发，在 256px 上训练 667 轮（20,010 次更新），生成 32 张并与 T1@128 做同屏五维对比。

**Architecture:** 不改网络结构与损失，只变分辨率。新增一个 `cfm256_t1_ac` 预设复用 `cfm128_hrsevere_pilot` 的数据口径（61 张），用 `--init_weights_only` 加载 T1 raw 权重；训练、验收、生成、拼图各一个脚本入口。

**Tech Stack:** PyTorch（现有 `ddpm/train.py`）、python-docx 无关、PIL、bash。

**Spec:** `generate_project/deep_learning/Fundus-FlowMatching/CFM/T1_256_PROTOCOL.md`

## Global Constraints

- 初始化只加载 `model_state_dict`（raw），优化器全新、EMA 重建；`--resume` 必须绝对路径。
- 必须显式 `--output_dir`，避免 preset 写回其它目录。
- 每 50 轮存档；主结果只认 `final_model.pth`，不允许中途挑 checkpoint。
- 原始数据 61 张，seed 42，损失 L1 + LPIPS 0.1 + color 0.01。
- 结果数字只登记 `generate_project/deep_learning/EXPERIMENTS.md`。

## Review Focus

- 128 权重 strict 加载进 256 配置：任何 missing/unexpected 都必须在开训前暴露，不能等到 10 小时后。
- 条件顺序：256 骨架排序前 8 张必须与 128 版同序，否则拼图列错位。
- 长训练风险：Modern Standby 会让 CUDA 挂起（11-13 已发生一次）；开跑前确认待机/显示器超时已关。
- 生成口径：raw / Euler 50 NFE，4 seed，与 T0/T1 一致。
